# Project Summary

FastManga is a Python command line manga reader and downloader prototype.

## Included now

- Search, read, download, popular, trending, config, and library CLI commands
- Local SQLite storage for manga, chapters, history, and bookmarks
- MangaDex provider with mock fallback data
- Reader and downloader utilities
- Core tests for models, config, database, and provider behavior

## Framing

This project is best presented as a learning project or early prototype.

## Strong parts

- Clear folder layout
- Useful core data models
- A practical CLI shape
- Better offline behavior than many small API demos

## Main future work

- More providers
- Better reader experience
- Cleaner packaging and release flow
- A real TUI if the project grows beyond CLI scope
